# Awesu-Sherif-Olawunmi-Ohm-s-Law-and-Power-Calculator-
A Python-based calculator for voltage, current, resistance and electrical power using Ohm's Law.
Ohm's Law and Power Calculator

What it does

The Ohm's Law and Power Calculator is a Python program designed to calculate voltage, current, resistance and electrical power in an electrical circuit.

The user selects the quantity they want to calculate, enters the known values, and receives the calculated answer with the correct unit. The program uses Ohm's Law and the electrical power formula.

How to run it

1. Install Python 3 or Pydroid 3 on Android.
2. Download or copy the Python file from this repository.
3. Open the file in your Python editor.
4. Run the program.

Filename: "ohms_law_power_calculator.py"

Run using the terminal:

python ohms_law_power_calculator.py

My own twist

I added a Complete Circuit Summary feature. After every calculation, the program displays voltage, current, resistance and power together.

I also added a Calculation History feature that stores previous calculations and allows users to review them. Input validation was included to prevent invalid entries and division by zero.
